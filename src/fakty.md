# Площадки — что известно (снято с place.search-api.ru 19.11.2026, вход админа)

Проект ИИ-кэмпа 2026, капитан — Евгений Авдеев. Команда, наставник, цели и эффект — НЕ ДАНЫ: на слайдах «уточняется» / пропуски.

Что это: внутренний инструмент работы с площадками (банкетные залы, лофты, рестораны, загородные, конференц-залы, концертные, спортивные, детские лофты). Ведёт человек — менеджер по площадкам.

Разделы: База · Запросы · Поля · Команда · Журнал. Оповещения в Telegram. Выгрузка в Excel. Архив.

База (19.11): всего 157 площадок; активные 62; ждут подписания 51; нужна проверка 59; давно не касались 153; без фото 41.
Фильтры: поиск по названию/метро/контакту/ИНН, тип площадки, статус, кейтеринг — доступ, гостей от…, формат, ещё фильтры.
Колонки списка: площадка с фото, адрес, тип, статус (Новая / Активная / Спящая), гостей (фуршет/банкет/театр), комиссия, договор, ответственный + «N дней без контакта» / «контакта не было», «пускают наше» (кейтеринг, оборудование — зелёный/жёлтый/красный), контакт.

Карточка площадки: фотогалерея, залы с площадью и вместимостью, договор и юрлицо, список незаполненных полей, история изменений.
Пример: «Академия Будущего» — спортивный объект, 6 залов-станций (от 1 500 до 13 600 м², до 5 000 гостей), 9 фото, договор не подписан.

Поля (настраиваются без программиста): тип, статус, адрес, сайт, расположение, площадь, залы (зал, м², фуршет, банкет, театр, без формата), условия аренды, комиссия %, кейтеринг — доступ, оборудование — доступ, аккредитация нашего кейтеринга, оснащение (оборудование, электричество, парковка), юрлицо/ИНН, тип договора (агентский / оказания услуг), статус договора (нет / не подписан / ждём подписания / подписан), контакты, папка с фото, ответственный менеджер, дата последнего контакта, следующий шаг, что проверить, ссылка на Битрикс. Ключевые поля — в списке и фильтрах. Поля можно скрывать — значения сохраняются.

Запросы: продажники отправляют запрос на подбор площадки; статусы Новый → В работе → Закрыт / Отменён. На 19.11 открытых нет.

Журнал (видят только админы): кто заходил, сколько дней, заходов, время в панели, карточек, поисков, фильтров, выгрузок в Excel, правок, запросов. Сегодня 19.11: заходили 9 из 37, 25 заходов, 1 ч 41 мин в панели. Пользователи — менеджеры по продажам и по площадкам.
